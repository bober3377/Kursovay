# Электронный учебник по информационным технологиям

Настольный шаблон курсового проекта на Python и Tkinter с базой PostgreSQL. pgAdmin 4 используется для администрирования PostgreSQL, но сам по себе не заменяет сервер базы данных.

## Возможности шаблона

- Регистрация студента и вход по логину и паролю — почта не нужна.
- Отдельная админ-панель для просмотра отправленных практик, открытия файла и выставления оценки.
- Генерация шаблонов Word и Excel с примером и заданием. Варианты предусмотрены для занятий №1, №3 и №5–9; руководство пользователя №2 выполняется по теме собственного ТЗ из занятия №1, поэтому отдельный вариант для него не нужен.
- Выдача одного из 30 вариантов для занятий с индивидуальными условиями и исходными данными: сценарии и критерии приёмки Word-заданий, условия договора, бюджеты, журналы событий, планы работ и наборы задач Excel. Выбранный вариант сохраняется за студентом и показывается преподавателю.
- Отдельная вкладка администратора с оценками за тесты всех студентов.
- Конструктор тестов в админ-панели: добавление, изменение и удаление вопросов трёх типов.
- Навигация по разделам в боковой панели, каталог учебных тем и отдельное окно чтения материалов.
- Хранение загруженных работ в PostgreSQL, чтобы преподаватель мог открыть их с другого компьютера.
- Учебные разделы и пример теста по каждому разделу.
- Перемешивание вопросов и вариантов ответов; поддержка одного ответа, нескольких ответов и свободного текстового ввода без учёта регистра и крайних пробелов.
- Автоматическая проверка теста и сохранение оценки по шкале 2–5.
- Загрузка файлов Word/Excel в общую базу PostgreSQL и список результатов.
- В шаблоне проверки практик предусмотрено сохранение отправленной работы. Автооценка появится после заполнения конкретных критериев; сейчас приложение не присваивает практической работе выдуманную оценку.

Учебные материалы и вопросы теста в `database.py` составлены кратко по рабочей программе «Офисные технологии»: основные определения дополнены примерами применения в заданиях. Генератор практик создаёт Word-документы и книги Excel с примером и заданием для студента. Пороговые значения оценки теста находятся в `logic.py`.

## Запуск

1. Установите Python 3.10 или новее. На Windows при установке Python включите компонент Tcl/Tk.
2. Установите и запустите PostgreSQL. Создайте пустую базу данных `electronic_textbook` в pgAdmin 4.
3. Откройте терминал в папке проекта и установите зависимости:

   ```powershell
   py -3 -m pip install -r requirements.txt
   ```

4. Запустите приложение один раз командой `py -3 main.py`. Если `config.ini` ещё нет, приложение создаст его и сообщит о настройке.
5. В `config.ini` рядом с `main.py` укажите пароль пользователя PostgreSQL и задайте логин и пароль первого администратора:

   ```ini
   [postgresql]
   host = localhost
   port = 5432
   dbname = electronic_textbook
   user = postgres
   password = пароль_пользователя_PostgreSQL

   [admin]
   username = admin
   password = admin1
   ```

6. Повторно выполните `py -3 main.py`. Таблицы и демонстрационные записи создаются автоматически. При первой настройке администратор входит с логином `admin` и паролем `admin1` (6 символов). Это простой пароль для локального демонстрационного запуска; не используйте его для реальных данных и поменяйте после первого входа, если приложение будет использоваться не только для показа курсового. Студенты регистрируются через форму. Не публикуйте `config.ini` и не отправляйте его другим людям: в нём находятся пароли.

Если ранее запускалась старая версия проекта, приложение добавит поле логина к существующей таблице студентов, а старые аккаунты получат логины вида `student_1`, `student_2` и т. д. Старые пароли сохранятся. Администратор из `[admin]` создаётся отдельно.

На рабочем столе Windows можно создать ярлык `Электронный учебник`, указав Python `pythonw.exe`, файл `D:\курсач\main.py` и рабочую папку `D:\курсач`. Студенту достаточно дважды щёлкнуть ярлык; на этом компьютере при этом должны быть установлены зависимости и запущен PostgreSQL.

## Сборка приложения для Windows

Сборку выполняй на Windows-компьютере с установленным Python. Один раз в папке проекта запусти PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File .\build_windows.ps1
```

Скрипт установит зависимости сборки и создаст `ElectronicTextbook-Windows.zip`. Архив содержит `ElectronicTextbook.exe` и шаблон `config.ini`. Перед запуском открой `config.ini` и впиши параметры подключения к серверу. Раздай папку приложения студентам через флешку или локальную сеть. Python на их компьютерах устанавливать не нужно. Не клади рабочий `config.ini` с паролем в общий архив; выдавай пароль отдельно только доверенным пользователям.

## PostgreSQL на компьютере преподавателя и подключение клиентов

1. Компьютер преподавателя должен оставаться включённым и подключённым к той же локальной сети. В настройках роутера зарезервируй за ним постоянный IP, например `192.168.1.50`.
2. Установи PostgreSQL на ПК преподавателя. В pgAdmin создай базу `electronic_textbook`. Запомни имя пользователя PostgreSQL и его пароль.
3. В pgAdmin открой Query Tool и узнай пути к файлам конфигурации:

   ```sql
   SHOW config_file;
   SHOW hba_file;
   ```

4. В `postgresql.conf` замени `listen_addresses` на IP сервера и localhost:

   ```conf
   listen_addresses = 'localhost,192.168.1.50'
   ```

   В `pg_hba.conf` добавь правило для своей подсети. Пример ниже разрешает подключение пользователя `postgres` только из сети `192.168.1.x`; подставь свою подсеть и фактическую роль базы:

   ```conf
   host    electronic_textbook    postgres    192.168.1.0/24    scram-sha-256
   ```

   Сохрани файлы и перезапусти службу PostgreSQL через приложение «Службы» Windows. Для курсового проекта можно использовать существующую роль, владеющую базой. Клиентам не нужна pgAdmin.
5. В брандмауэре Windows на ПК преподавателя разреши входящие TCP-подключения к порту `5432` только для частной сети. Не открывай этот порт в интернет и не настраивай перенаправление портов на роутере.
6. На ПК преподавателя распакуй приложение. В его `config.ini` укажи `host = 127.0.0.1`, а также `dbname`, пользователя и пароль. Запусти `ElectronicTextbook.exe`; приложение создаст нужные таблицы и начальные записи в выбранной базе.
7. На каждом студенческом ПК распакуй архив в отдельную папку и в `config.ini` укажи те же параметры базы, но `host = 192.168.1.50` (IP компьютера преподавателя). Пример:

   ```ini
   [postgresql]
   host = 192.168.1.50
   port = 5432
   dbname = electronic_textbook
   user = postgres
   password = пароль_пользователя_PostgreSQL

   [admin]
   username = admin
   password = admin1
   ```

   Используй пароль роли PostgreSQL, а не пароль администраторского аккаунта приложения. Учётные данные PostgreSQL в текущей архитектуре находятся в конфигурации клиентского приложения, поэтому подключай к ней только доверенные ПК в локальной сети. Не передавай архив с рабочим `config.ini`.
8. На клиентском ПК проверь соединение командой:

   ```powershell
   Test-NetConnection 192.168.1.50 -Port 5432
   ```

Файлы студенческих работ сохраняются в PostgreSQL (`BYTEA`), поэтому преподаватель видит и открывает новые отправки из админ-панели. Старые работы, которые ранее сохранялись только на диске, автоматически в базу не переносятся. Делай резервные копии базы PostgreSQL; размер каждой отправляемой работы ограничен 20 МБ.

Для запуска тестов:

```powershell
py -3 -m unittest discover -s tests
```

## Структура данных

`schema.sql` описывает таблицы студентов, учебных разделов, вопросов, попыток теста, практических заданий и отправленных работ. В `practice_tasks.rubric` зарезервировано поле для критериев будущей автопроверки. Настоящую проверку Word/Excel нужно реализовать под конкретные требования задания, когда они будут известны.
